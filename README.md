# Event Management Website

## About the Project

The Event Management Website is a web-based project developed to make it easier for students to explore and get information about different college events. It provides a simple interface where users can browse upcoming events, search for specific events and view all the important details in one place.

The website is built using HTML, CSS and JavaScript, with a focus on simple navigation and a user-friendly design.

## Features

- **Upcoming Events:** Displays a list of upcoming college events with their basic information.
- **Search Functionality:** Allows users to search for events by name, category or location.
- **Event Details:** Users can view detailed information about an event, including its date, time, venue, entry fee and description.
- **Countdown Timer:** Shows the time remaining before an upcoming event starts.
- **Dark and Light Mode:** Users can switch between dark and light themes.
- **Responsive Design:** The website layout adjusts to different screen sizes, including mobile phones and desktops.
- **Easy Navigation:** Simple navigation links make it easier to move between different sections of the website.

## Technologies Used

- **HTML5:** Used to create the structure of the website.
- **CSS3:** Used for styling, layout, colours and responsive design.
- **JavaScript:** Used to add functionality such as event searching, countdown timers, theme switching and displaying event details.

1. Download or clone this repository to your computer.
2. Open the downloaded project folder in VS Code or any code editor.
3. Open the `index.html` file in your web browser.
4. You can now explore the website and use its features.
